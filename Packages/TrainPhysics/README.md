# RailwayTrainPhysics

架空の列車ゲーム専用、Foundationのみで構成したSwift物理モジュールです。編成内各車の質量・制動諸元、120Hz縦運動、ブレーキ管/シリンダ圧、熱フェード、粘着制限と再粘着、駆動電流/電圧、回生・空気制動の境界、固定tick上の停車距離推定を独立してテストできるようにしています。

> **警告 — ゲーム用途のみ**  
> 同梱プロフィールの質量、制動力、圧力、粘着係数、電流、電圧、抵抗・熱定数はすべて架空のゲーム用値です。実車仕様や規程への適合を示さず、実車の安全計算、運転・訓練・保安装置設定、制動距離保証、設計判断には使用できません。現実の列車は、資格ある専門家が検証済みの実車データと規程に基づいて評価する必要があります。

## 対象プロフィール

既存ゲームで選べる5方式を別プロフィールとして収録しています。抵抗制御T-02（4両）、界磁チョッパT-01（6両）、VVVF GTO T-03（6両）、VVVF IGBT T-04（8両）、VVVF SiC T-05（8両）です。加えて `FictionalFormationCatalog` が、VVVF・界磁チョッパ・抵抗制御の8両と10両を同じローダへ足します。10両は主電動機数を8両と同じ4Mに固定し、付随車2両を足して総質量を増やし、その2両のブレーキ力は他車より小さくしています。ブレーキ管の遅れは1両あたりの時定数のままなので、両数が多いほど後位の込めが遅れます。数値は制御方式と編成長、および公開BVEページに書かれた操作（定速、並列最終段後の回生と0A、1ノッチでの進段停止、マスコン逆回しの抑速）から置いたPLACEHOLDER / fictionalizedです。出典ページは `FictionalPageDescribedControl.swift` に記しています。公式空車質量・引張力・減速度ではなく、アドオンのファイルは含みません。西武4000系の10両は、そのページが4両と8両だけを挙げているため追加PLACEHOLDERです。各車には個別の空車質量、乗車定員、動軸/制動軸の割合、常用/非常ブレーキ力、応答時間、熱容量・冷却・フェード曲線があります。JSONの数値も、既存のゲームプロフィールをつなぐための架空プレースホルダーで、実車性能データではありません。

牽引力は「低速の力一定 → 基準速度以降の出力上限 → 高速域での電圧制限相当の出力低下」を連続な区分式で近似し、ノッチ投入の牽引力変化にはプロフィール別のジャーク上限（同梱値は架空の0.65 m/s³）を適用します。抵抗制御・界磁チョッパはゲーム内ノッチ段階、各VVVFは別ノッチ配列と力/出力/速度/電流枠を持ちます。これは回路・半導体スイッチング・モーター磁束の詳細モデルではありません。回生力は速度フェード、最大回生力/電力、方式ごとの回生分担率から要求値を作り、粘着上限を超えた分は摩擦ブレーキ側へ回します。実装の電流計は力と速度から作る演出用の符号付き電流概算です。

## 単位と更新契約

| 量 | API単位 |
|---|---|
| 車両質量・乗客質量 | kg（乗客1人60 kg、乗車率0〜2） |
| 距離・位置・曲線半径 | m |
| 速度 | m/s。プロフィール・線路速度制限と回生境界はkm/hで受け、更新境界で換算 |
| 加速度 | m/s² |
| 力 | N |
| 出力 | W |
| 電流・架線相当電圧 | A / V |
| ブレーキ管・シリンダ・元空気ダメ圧 | kPa |
| 勾配 | ‰（進行方向に上りが正） |
| ブレーキ温度 | °C。熱容量J/°C、冷却W/°C |
| 時間 | s。固定tickは厳密に `1/120 s` |

Davis抵抗は `mass[tonne] × (a[N/tonne] + b[N·s/(m·tonne)] × v[m/s]) + c[N·s²/m²] × v²`。曲線抵抗は `mass[kg] × g / 1000 × coefficient[N·m/kN] / radius[m]` です。正の勾配は重力に逆らう力、負の勾配は重力に助けられる力として符号付きで計算します。

公開更新口は `advance(realDeltaSeconds:controls:track:surface:modifiers:)` のみです。1回に受け付ける実時間差分は最大0.5秒に制限し、残差を蓄積して整数個の1/120秒tickだけ進めます。描画レートのdtで物理計算しません。線路条件はtick内一定、積分はsemi-implicit Euler（速度更新後に距離更新）です。

ブレーキ管は先頭車の弁操作を起点に各車が上流の直前tick圧力を追う一次遅れの伝播近似、シリンダは車両別の立上り/緩め時定数で追従します。各車の摩擦ブレーキ温度は摩擦仕事から上がり、冷却し、指定温度域で力を減衰させます。回生・摩擦・各車の粘着上限、編成全体の速度/位置/力/電気量をtelemetryで観測できます。

## 入力の境界と数値安定性

- プロフィールはエンジン生成前に検証し、不正な車両数・重複ID・非有限値・負質量/力・不整合なブレーキ圧/速度/ノッチ配列に加え、異常に大きな質量・力・出力・電気/熱値も拒否します（車両質量は1両250 t以下、編成16両以下、速度500 km/h以下等）。
- 乗車率は0〜2へ制限。制御ノッチは計算時に有効範囲へ制限。負/非有限速度は力曲線側で停止速度として扱い、速度の負値やNaNを状態へ残しません。
- 線路入力範囲: 勾配±250‰、速度制限0〜500 km/h、トンネル倍率1〜4、半径は正の有限値、電圧は正かつ100 kV以下。`TrackCondition.isValid == false` の入力は全体をlevel trackへ置き換えます。
- modifierの牽引/制動倍率は0〜2、粘着係数overrideは0.01〜1、速度上限は0〜500 km/hへ制限。非有限modifierは中立値に戻します。
- 速度・温度・圧力・力の状態を有限値に保ち、常に速度を0以上にクランプします。停車距離推定には最大600秒の上限を設定し、期限内に停止できなければ `reachedRest == false` を返します。
- 路線終端・駅マーカーで位置を自動停止させる機能はありません。推定停止距離は、現在状態のコピーへ同じ固定tickでブレーキを掛けるゲーム計測値です。信号・地形の将来変化や実車保証は含みません。

## ビルド・テスト手順

Mac/Xcode環境で実行してください。

```sh
cd Packages/TrainPhysics
swift test
```

モジュール名は `TrainPhysics`、Xcode product `RailwayTrainPhysics` はこのプロジェクトのapp targetへリンク済みです。公式Swift 6.4.2 Linux（x86_64）で`swift test`を実行し、19件すべて合格しました。報告されていた2箇所のclosure argumentエラーは未使用引数を明示して修正し、テストの`PhysicsModifiers`引数順も宣言に合わせました。また、1 tickでの移動を前提にしていたテストは、ジャーク制限により初tickの牽引力が走行抵抗を下回り得るため、牽引力が適用されたことを確認する形に直しています。復元エラー文の車両ID補間も修正しました。これはLinuxパッケージテストの結果であり、iOSビルド、Xcode、Simulator／実機動作は未確認です。詳細と受け入れ試験は[`../../TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md)を参照してください。
