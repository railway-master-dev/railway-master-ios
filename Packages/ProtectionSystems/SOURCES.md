# 公開資料と適用範囲

この一覧は、パッケージ内の**一般的な概念**を確認するために使った公開一次資料です。資料が対象とする事業者・型式・時点・個別事故の範囲を越えて、実在の装置すべてに適用される仕様だとは扱いません。リンク先の説明や図表は概要・事例であり、非公開の設計書・運転取扱規程・適合認証資料の代わりではありません。

## ATS-S / ATS-P / ATS-Ps

- [ATS-P形保安装置の導入について](https://www.jreast.co.jp/press/1998_1/19980504/index.html) — JR東日本。停止信号までの距離情報を用いる連続速度照査パターンと、パターンを超えた場合の自動ブレーキという機能概要。ATS-Pの全社共通内部式・定数の資料ではありません。
- [ATS-P、Ps装置の整備拡大および曲線等の速度超過防止対策](https://www.jreast.co.jp/press/2005_1/20050610.pdf) — JR東日本。ATS-Psを含む同社の装置説明・図解、設備整備の資料。個別図解を全事業者・全型式へ一般化しません。
- [JR東日本グループ CSR報告書2017・安全](https://www.jreast.co.jp/eco/report/pdf_2017/p30-50.pdf) — JR東日本。ATS-P/Ps、ATC等の概要。2017年時点の事業者説明です。
- [JR EAST Technical Review No.3「世界一安全な鉄道」の実現](https://www.jreast.co.jp/development/tech/pdf_3/04-08.pdf) — JR東日本。ATS-S、ATS-SN、ATS-P/Psの歴史・機能差の説明。JR東日本の技術紹介です。
- [ATS-SW形を含む用語集](https://jtsb.mlit.go.jp/ikenrail/shiryou/20070201-an05-yougosyu.pdf) — 国土交通省・運輸安全委員会。ATS-SW形の確認扱いや5秒の記述等、限定された型式説明を含みます。ATS-S一般仕様と同一視しません。
- [福知山線事故関連・提言案要約資料2](https://jtsb.mlit.go.jp/fukuchiyama/kensyou/fu04-shiryou2-20110415.pdf) — 運輸安全委員会の公開検証資料。初期ATS-Sに関する概要説明の例です。ATS-S全型式の仕様書ではありません。
- [福知山線事故調査報告書関連資料・付録2-2](https://jtsb.mlit.go.jp/fukuchiyama/kensyou/fu04-finalreport-annex-2-2.pdf) — 国土交通省・運輸安全委員会。ATS-Pの車上パターン計算、常用最大ブレーキ、曲線用照査等に関する調査資料の説明範囲です。

## ATC / ATO / EB

- [デジタルATCの開発と導入](https://www.jreast.co.jp/development/tech/pdf_20/Tech-20-38-42.pdf) — JR EAST Technical Review No.20。JR東日本のデジタルATCについて、停止区間・車上位置／速度・パターン照査の概要を説明します。全ATC方式の共通仕様ではありません。
- [鉄道における自動運転技術検討会 とりまとめ](https://www.mlit.go.jp/tetudo/content/001512132.pdf) — 国土交通省。GoA、システム総体の安全確保、ATOを含む自動運転の技術的検討。個別事業者のATO内部ロジックを定義するものではありません。
- [鉄道における自動運転を導入する場合の技術的要件の検討](https://www.mlit.go.jp/tetudo/tetudo_fr7_000027.html) — 国土交通省。一般路線への自動運転導入に向けた検討の背景・方向性。
- [国土交通白書「鉄道の自動運転（GOA2.5）」](https://www.mlit.go.jp/hakusyo/mlit/r06/hakusho/r07/html/n1212c05.html) — 国土交通省。JR九州香椎線の特定構成例としての車上ATO、位置情報・信号制御情報、駅間速度調整の説明です。
- [EB装置の用語説明を含む資料](https://jtsb.mlit.go.jp/ikenrail/shiryou/20070201-an05-yougosyu.pdf) — 国土交通省・運輸安全委員会。無操作後の警報・非常ブレーキについて特定装置を説明する例です。記載時間を全形式共通値にしません。
- [鉄道に関する技術上の基準の改正概要](https://www.mlit.go.jp/kisha/kisha06/08/080324_.html) — 国土交通省。運転士異常時に列車を自動停止させる装置の設置義務化という制度目的の説明。
- [JR西日本・EB装置が機能しない状態で走行した事象](https://www.westjr.co.jp/press/article/2015/04/page_7058.html) — 西日本旅客鉄道。特定事象・特定装置の操作監視時間等の公開説明。一般仕様の根拠にはしません。

## 信号・閉そく・連動・CTC / PRC

- [信号（鉄道建設技術）](https://www.jrtt.go.jp/construction/technology/signal.html) — 鉄道建設・運輸施設整備支援機構（JRTT）。軌道回路、閉そく、信号、ATS/ATC、転てつ器・連動装置の一般的な役割紹介。速度・現示の例は線区により異なります。
- [列車制御・保安分野検討WG報告資料](https://www.mlit.go.jp/common/001322382.pdf) — 国土交通省鉄道局・交通安全環境研究所。軌道回路・閉そく・列車位置検知の構成例と安全側機能に関する検討資料。
- [梶が谷駅構内事故の経過報告](https://jtsb.mlit.go.jp/railway/rep-acci/keika20261001-1.pdf) — 運輸安全委員会。特定事故・設備の軌道回路、転てつ器、連動に関する記録であり、全事業者共通の回路仕様ではありません。
- [PRC・CTCを含む鉄道分野の制度解説](https://www.mlit.go.jp/sogoseisaku/jouhouka/content/001860206.pdf) — 国土交通省。遠隔運行管理・進路制御に関わる設備範囲の制度的な説明。
- [鉄道重大インシデント調査報告書（2009年）](https://jtsb.mlit.go.jp/railway/rep-inci/RI2009-3-1.pdf) — 運輸安全委員会。PRCをダイヤに基づく進路制御の自動化として定義する記述を含みます。
- [運行管理システムの変革](https://www.jreast.co.jp/development/tech/pdf_5/12-20.pdf) — JR EAST Technical Review No.5。JR東日本のCTC・PRC・ATOS等の機能・構成例であり、他事業者の仕様ではありません。

## 資料だけでは確定しないもの

以下はこのパッケージで実装する場合も、独自の架空設定に限定します。実在値として補っていません。

- 型式・事業者・線区ごとのATS/ATC速度パターン、制動曲線、減速度、車両補正、粘着・勾配補正、数値余裕、応答周期・通信遅延
- ATS-S／ATS-P／ATS-Ps個別の地上子電文・設置間隔・位置・確認入力の全成立条件・警報やブレーキの解除／復帰条件
- ATOの実装アルゴリズム、加速度・ジャーク・停止許容誤差、起動・解除条件、通信・測位故障時の個別動作
- EB・デッドマンの車種別入力監視対象、タイマー、警報・解除・復帰条件
- 実在路線の閉そく境界、信号現示・速度対応、連動図表、鎖錠・解錠、転てつ器の詳細
- CTC／PRCの事業者固有進路優先度、遅延・ダイヤ変更時の再計画、競合時判断、故障・通信断の復旧ロジック

これらを実車データに置き換えるには、対象の事業者・線区・車種について許諾と信頼できる仕様資料が必要です。本パッケージはその確認・接続を実施していません。
