# Original scenery surfaces

The `scenery_*.png` files in this folder are original procedural images generated by `Scripts/build_original_scenery_textures.py`. They contain no downloaded photograph, cab reference photo, BVE or openBVE image, game screenshot, or map imagery.

Commercial use inside this application is allowed because the pixels are original. They are not photoreal scans and they are not a claim of real materials. Rebuild them with:

```sh
python3 Scripts/build_original_scenery_textures.py
```
