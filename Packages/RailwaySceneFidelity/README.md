# RailwaySceneFidelity

iOS RealityKit 向けのオリジナル手続き型の鉄道回廊・沿線環境モジュールです。線路・バラスト・枕木・締結装置・架線、ホーム・駅設備、道路・車両、建物・人物・植生に加え、チェーン数で決まる架空の橋・切取・築堤・静的踏切を、路線の曲線接線に沿って構成します。高品質のアプリ経路はこのビルダーを呼びます。低/中品質はアプリ側が同じ `SceneCorridorLandmarkSchedule` を粗い箱で描きます。外部アセット依存はありません。

## まず知っておくこと

- 座標はメートル基準で、`X` は路線右側、`Y` は上、`Z` は進行方向です。経路は単なる繰り返し平面ではなく、チェーン数を媒介変数とする cubic Hermite 曲線です。制御点ごとの接線を明示するか、未指定なら隣接点から推定します。
- 全ての周辺モデルはこのPackage独自の幾何プリミティブから作る**合成プレースホルダー**です。`syntheticPlaceholderLabel` と RealityKit Entity 名にもその旨を付けています。実測、写真測量、著作アセット、実在駅・建物・人物・車種の再現ではありません。
- 高密度メッシュ化は、著作フォトリアル資産や写真測量と同等ではありません。マテリアルは無地の色・roughnessを割り当てる初期パレットで、UVテクスチャ、実写表面、物理計測済みの損傷や個別駅ディテールは含みません。
- `RailwayRealityKitSceneAdapter.build(plan:camera:surfaceWeather:)` に`SceneSurfaceWeather`を渡すと、湿潤で色をわずかに暗くしroughnessを下げ、積雪量で対象材質を明るく粗くします。`updateSurfaceWeather(_:)`は生成済み材質をその場で更新し、wetness/snowのどちらも0.05未満の差は間引きます。これは単色プレースホルダー応答で、濡れ層・雪ジオメトリ・雨粒・滑りやすさを表すものではありません。既定は乾燥です。
- iPhone上のFPS、発熱、メモリー、電池消費は測定していません。密度値・LOD距離・形状数は設計上の初期ヒューリスティックであり、性能保証ではありません。

## 含まれる構成

| 分野 | 生成内容 |
|---|---|
| 軌道 | 連続バラスト床・路盤、左右レール、実寸指定の枕木、ベースプレート、左右のクリップ |
| 電化 | 支持柱、基礎、帯金、片持ち腕、碍子、支持金具、接触線・吊架線・ドロッパー |
| 駅 | 指定チェーン数区間のホーム床、縁端帯、点字警告タイル、上屋、柱、照明、ベンチ |
| 街路・沿線 | 路線に沿う舗装・縁石・歩道・車線標示、合成乗用車、窓や車輪などの部品 |
| 景観 | 変化をつけた建物外形・窓・庇・バルコニー・雨どい、人物の簡易シルエット、幹・枝・樹冠 |
| 沿線ビート | 1,600 m 周期の架空の橋（桁・高欄・橋脚・水面）、切取擁壁、築堤法面、静的踏切。`PLACEHOLDER`。踏切は連動せず列車を止めない。駅ホームと重なる区間は置かない |
| カメラ・品質 | カメラ距離と視錐台による球体カリング、near/mid/far LOD目安、景観アセンブリー上限、詳細レベル・表示距離設定 |

## Package構成

- `Sources/RailwaySceneFidelity/Geometry.swift`: 値型ベクトル、路線制御点、チェーン数曲線補間、接線・バンクを含む局所フレーム、カメラ状態。
- `SceneTypes.swift`: 回廊寸法、ホーム仕様、部材・材料・LOD、密度設定、シーン計画型とカリング方針。
- `ScenePlanBuilder.swift`: 決定論的な部材・周辺環境配置。
- `RealityKitSceneAdapter.swift`: iOS/RealityKit/UIKit がある場合だけ有効。`MeshDescriptor` で部材を材料別にアセンブリー単位へメッシュ一括化し、LOD別の形状生成・表示切替と湿潤/積雪色・roughness応答を行います。Core側はRealityKitに依存しません。
- `Tests/RailwaySceneFidelityTests/`: 補間、曲線、寸法、密度、カリング、プレースホルダー表示、weather値の範囲制限、架空沿線ビートのスケジュールと都市景観の回避のテスト。

## 検証

Swift/Xcode が使える環境で、このフォルダーから `swift test` を実行してください。RealityKitのビルドはiOS SDK/Xcodeで確認してください。

2026-11-06 に Swift 6.4.2 Linux でこの Package の `swift test` を実行し、13 件 pass / 0 fail でした（既存スイートに架空沿線ビート 4 件を含む）。これは iOS 型検査、RealityKit 描画、実機性能の確認ではありません。Python で行える契約チェックは次を実行します。

```bash
python3 Scripts/validate_scene_fidelity.py
```

この静的検証はSwiftコンパイルやテストの成功を代替しません。
