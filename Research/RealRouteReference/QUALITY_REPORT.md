# 京都—東寺の検証結果と限界

## 収録した値

国土交通省の2025年度「国土数値情報（鉄道）N02-25」から、近鉄京都線の京都—東寺に対応する路線リンク線形1件と駅線形2件を抽出しました。データ基準日は2025年12月31日、メタデータのdateStampは2026年3月6日です。座標系は **JGD2011 / (B,L)**、メタデータの縮尺相当値は1:25,000です。取得したZIPのSHA-256は次のとおりです。

`aaf76af133b2e771e538fabc4646d2e443dc1d5a67b221382a28d744e706cc9f`

駅間の路線リンクには16頂点があります。元データの順序は東寺側から京都側なので、パッケージでは頂点を反転し、chainageを京都側0.0 mから東寺側801.5 mへ増えるよう定義しました。GRS80楕円体の逆測地計算の未丸め合計は約801.456 mで、独立したGeographicLib実装でも同値を確認しています。公開線形の隣接頂点間距離は最大約230.8 mです。両端は駅線形featureの端点と座標値が一致します。地図線形から導いた距離・chainageのstatusは、線路実測値と誤認されないよう `ESTIMATED` としています。

この **801.5 mは公開route-lineに沿う算出値**で、運行上の正式キロ程、駅中心間の距離、個々のレールの測量長ではありません。駅線形は線として公開されているため、駅中心・ホーム端・列車停止位置は定まりません。

## 別資料の距離は別の定義

- 近鉄の[公式営業キロ程表（PDF）](https://www.kintetsu.co.jp/gyoumu/kippu/pdf/kirotei_20260314.pdf)は京都—東寺を **1.1 km** と示します。文書中の日付表示は「令和5年4月1日」ですが、ファイル名には「20260314」が含まれます。現時点でどの日付が現行性を示すかは確認できていないため、この営業キロはJSONに取り込まず `officialCommercialDistanceM` を `UNKNOWN` としました。
- 京都市の[近鉄関連事業ページ](https://www.city.kyoto.lg.jp/kensetu/page/0000040405.html)は、京都—東寺の連続立体交差事業を **0.9 km、踏切3箇所除去、昭和44年度（1969年度）完了**と記載します。これは事業区間の長さで、線路長・営業キロではありません。高架化という広い事実は確認できますが、区間内の構造物境界・高さ・桁・橋脚の正確な位置は示さないため、データには構造物chainageを作っていません。

したがって、801.5 m（公開線形からの計算）、1.1 km（営業キロ表）、0.9 km（歴史的な事業延長）は異なる量です。相互に置き換えたり、シミュレーター用の線路長として一つを選んだりしていません。

## 品質と未確定事項

国土数値情報の製品仕様書は、位置座標を参照元と照合する品質検査を記述し、該当データのページは位置誤率0%としています。これは参照資料との座標一致率であり、実線路を地上測量した絶対誤差が0 mという意味ではありません。データには1:25,000相当の縮尺表示がありますが、メートル単位の絶対位置誤差・誤差分布は確認できません。座標の小数桁数から位置精度を推定していません。

現状を実装上、次のように限定しています。

- 座標・路線名・駅名：N02-25に掲載された値として記録。線形は国土スケールのroute/station表現であり、実測レール中心線ではありません。
- `totalLengthM`、線形頂点chainage：N02座標からの測地距離計算値（0.1 m単位）、confidence `LOW`、物理位置誤差は不明。
- 曲線半径・緩和曲線・カント・勾配・レール標高：`UNKNOWN`。
- 個別線路数・軌間・線路間隔・軌道構造・レール断面・枕木：`UNKNOWN`。
- 制限速度、信号機・現示、閉そく、ATS/連動、分岐器：`UNKNOWN`。空配列は「設備なし」ではなく「このデータに資料がない」を意味します。
- 駅中心座標・ホーム・停止位置・駅配線・構造物の正確な位置・線路設備：`UNKNOWN`。
- 走行距離の根拠となる物理線路長・ネットワーク長・時刻表・運転シナリオ：`UNKNOWN`。

このため、パッケージは地図上の参照線形と出典付きデータ契約には使えますが、列車物理・制限速度・信号制御・ホーム停車の実線区シミュレーションには使えません。詳しくは `INTEGRATION.md` を参照してください。

## 自動確認

`Tools/validate_route_package.py` はPASSしました。出典・SHA-256、route 16頂点・station 2件、駅線形との端点一致、chainageの単調性、距離再計算、250 mの最大geometry gap方針、物理・信号の重要値がUNKNOWNのままか、空配列を「なし」と誤読しない注記を確認しています。結果は距離801.5 m、最大頂点間隔230.801 m、最小頂点間隔7.781 m、入力ZIPのSHA-256一致です。

既存Swift `RailwayRouteData` モデルに対する別テストを `Tests/RealRoutePackageTests.swift` に用意しています。このテストは今回の20 Package matrixに含まれておらず、未実行です。今回passした`RailwayRouteData` package build-only結果と混同しないでください。
