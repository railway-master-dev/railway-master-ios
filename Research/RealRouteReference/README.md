# 近鉄京都線「京都—東寺」実路線参照データ

**状態:** 2025年度の国土交通省・国土数値情報から抽出した、1駅間の路線線形と駅線形です。アプリ本体にはまだ統合していません。実線路・運転設備の完全なシミュレーション用データではありません。

## すぐ確認するファイル

- `Data/route-package.json` — 既存 `RailwayRouteData.RoutePackage` モデルの形に合わせたデータ
- `Data/route_geometry.geojson` — 路線線形1件と駅線形2件。駅線形を点やホーム形状に読み替えていません
- `Data/source_manifest.json` — 入手日、出典、ライセンス、入力ZIPのSHA-256
- `QUALITY_REPORT.md` — 検証値、異なる距離定義、精度の限界、未確定事項
- `LICENSES.md` — 出典表示と再利用上の注意
- `INTEGRATION.md` — 既存iOS物理・描画コードへ安全に渡す際の条件

## 収録内容

- 近鉄京都線の京都駅—東寺駅間に相当する国土数値情報の路線リンク線形：16頂点、パッケージ内の局所chainageは京都側から東寺側へ **0.0–801.5 m**。
- 駅の公式線形レコード：京都駅1件、東寺駅1件。いずれも入力データどおりの線形で、駅中心点・停止位置・ホームとは別物です。
- route-packageの各値に、出典、状態、confidence、unknownの理由を記録しています。物理・信号に必要な未確認値は `UNKNOWN` のままで、推測値や placeholder 数値は入れていません。

801.5 mは、公開地図線形の頂点間をGRS80楕円体の測地距離で合計し0.1 m単位に丸めた値です。運行上の営業キロでも、測量されたレール長でも、駅中心間距離でもありません。点間隔が最大約230.8 mあるため、細かな曲線設計や線路レンダリングにも使えません。

## 再生成と検証

同梱のPython 3スクリプトで再生成/検証できます。再生成時は国土交通省の公開アーカイブを取得し、SHA-256が固定値と一致しない場合に停止します。アーカイブそのものは同梱していません。

```bash
python3 Tools/build_route_package.py --retrieved-at 2026-11-06
python3 Tools/validate_route_package.py
```

これは調査用のデータ/ツール束であり、独立したSwift Packageやアプリの運転路線ではありません。iOSのRouteData型への変換、描画、物理・信号・時刻表への接続は未実施です。特にこの線形だけでは物理的なレール長、駅中心、停止位置、軌間、線路構造、勾配、信号を確定できません。Xcode/iOS統合は別工程で品質と整合性を評価してください。
